# Anonymous reviewer artifact deployment

This is a clean source snapshot with no Git history. Its directory contents should be
committed to a **new private GitHub repository**; do not fork the original public repository.

1. From the extracted folder, check the README and run the validation commands.
2. Create a new private GitHub repository and commit only the files in this folder.
3. At https://anonymous.4open.science/ sign in using GitHub and grant the GitHub App
   read-only access to the chosen private repository only.
4. Generate an anonymous mirror link, open it in a signed-out/incognito browser,
   inspect the README, notebooks, plots and ZIP download for identity disclosures,
   and verify the link remains readable without GitHub login.
5. Supply **only the anonymous mirror link** in reviewer-facing materials.

The companion model-weight/export archive is not provided in this source snapshot.
Saved numerical records and scripts required for the reported-statistic checks remain included.
